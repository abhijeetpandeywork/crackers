  if (lineQty >= settings.wholesaleQtyThreshold) → use Tier 2
  Default threshold = 10. Config in Settings collection.
  Applied per line item, not total cart.
  Applies to ALL customer types including RETAIL and WALK_IN.
  API response MUST include: resolutionReason + bulkRateApplied: bool

RULE 3 — STOCK LEDGER IS IMMUTABLE:
  StockLedger = append-only. NEVER update or delete records.
  Add pre-save hook that throws Error on any update attempt.
  Current stock = SUM(IN) - SUM(OUT/DAMAGE/RESERVE) via MongoDB aggregation.
  Types: IN, OUT, MOVE, ADJUST, DAMAGE, RESERVE, UNRESERVE

RULE 4 — COUPON VALIDATION IS ALWAYS SERVER-SIDE:
  Client sends {code, cartTotal, customerId, channel} to POST /coupons/validate

  Coupon usage recorded ONLY after order confirmed, not at validation.

  async getStockLevel(productId, variantId, locationId):
    MongoDB aggregation on StockLedger:
      $match: { productId, variantId, locationId }
      $group: { _id: null,
                inQty: $sum of qty where type IN ['IN','UNRESERVE'],
                outQty: $sum of qty where type IN ['OUT','DAMAGE','RESERVE','ADJUST_OUT'],
                adjustIn: $sum where type=ADJUST and qty > 0,
                adjustOut: $sum where type=ADJUST and qty < 0 }
    Return: inQty + adjustIn - outQty + adjustOut
    NOTE: ADJUST records use positive qty for additions, negative for subtractions

  async validateCoupon({ code, cartTotal, customerId, channel, items[] }):
    1. Find coupon by code (case-insensitive). If not found: return {valid:false, error:'NOT_FOUND'}
    2. Check status==='active'. If not: return {valid:false, error:'COUPON_INACTIVE'}
    3. Check now >= validFrom AND now <= validUntil. If not: return {valid:false, error:'EXPIRED'}
    4. Check usageLimit===0 OR usedCount < usageLimit. If not: return {valid:false, error:'LIMIT_REACHED'}
    5. Check perCustomerLimit: if set, query CouponUsage.count({couponId, customerId}) < limit
    6. Check channel in coupon.applicableChannels OR coupon.applicableChannels includes 'ALL'
    7. If customerId: load customer type. Check customerType in coupon.applicableCustomerTypes
    8. Check cartTotal >= coupon.minOrderValue
    9. Calculate discountAmount:
       flat: min(coupon.discountValue, cartTotal)
       percent: min(cartTotal * discountValue/100, maxDiscountCap||Infinity)
       minorder: flat discountValue
       bxgy: (floor(itemQty/buyQty) * getQty) * itemPrice
       bundle/firstorder/agentpromo: same as flat or percent
    10. Return {valid:true, discountAmount, discountDescription, couponId}

  IMPORTANT: validateCoupon NEVER modifies the coupon document.
  Coupon usage only recorded AFTER order/invoice confirmed.

  async parseBrochure(buffer, priceListId, customerId, userRole):

    Find header row (row 1). Build column map by header name (case-insensitive).
    IF 'code' column not found: throw Error('Column structure not recognised. Expected Code header in first row.')
    IF 'qty' column not found: throw Error('Column structure not recognised. Expected Qty header.')
    Iterate rows starting row 2:
      code = row.getCell(codeColIdx).text.trim()
      qty = parseInt(row.getCell(qtyColIdx).text)
      remarks = row.getCell(remarksColIdx)?.text || ''
      IF qty <= 0 OR isNaN(qty): skip row silently
      product = await Product.findOne({ code: code, status: 'Active' })
      IF not found: push to unmatchedCodes[] and continue
      Determine variant (match by pack content from Col C if available, else use first variant)
      price = await pricing.service.resolvePrice({productId, variantId, qty, customerId, channel:'ERP_WHOLESALE_ESTIMATE', priceListId, userRole})
      push to matchedItems[]
    Return { matchedItems[], unmatchedCodes[], totalRows, matchedCount }

GLOBAL CODE QUALITY STANDARDS
=========================================================

These standards apply to EVERY file. Enforce throughout.

ASYNC: Every async route handler wrapped in asyncHandler middleware.
RESPONSES: Every controller uses success() or error() from utils/response.js.
LOGGING: Use winston logger, never console.log in production code.
SECRETS: Zero hardcoded credentials. All from process.env.
AUTH: Refresh tokens in httpOnly cookies, not localStorage.
S3: Never expose S3 URLs directly. Always presigned URLs.
PAGINATION: All list endpoints paginate. Default limit 20, max 100.
INDEXES: Create all MongoDB indexes on first-run (model definitions).
LEAN: All Mongoose read queries use .lean() unless modifying.
VALIDATION: Zod schemas validate ALL API inputs before controllers run.
AUDIT: All mutations (POST/PUT/PATCH/DELETE) logged to AuditLog.
ESLINT: npm run lint must pass with 0 errors on final build.
SECURITY: bcrypt 12 rounds, helmet on all responses, rate limiting on auth.
ERRORS: Never expose stack traces in production (NODE_ENV=production).
JOBS: Heavy operations (PDF, Excel export, notifications) ALWAYS in Bull queue.
SOCKET: Stock updates emitted after EVERY stock movement. Low stock checked after every OUT.
